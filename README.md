# Control Flow Exercises

Two beginner-friendly Java console programs demonstrating loops, conditional statements, and input validation.

## Programs

- `PrimeChecker.java`: checks whether an integer is prime.
- `FibonacciGenerator.java`: prints a Fibonacci sequence for a requested number of terms.

## Requirements

- Java Development Kit (JDK 8 or later)

## Compile and run

From the project root:

```bash
javac src/PrimeChecker.java
java -cp src PrimeChecker
```

```bash
javac src/FibonacciGenerator.java
java -cp src FibonacciGenerator
```

## Example output

Prime checker:

```text
Enter a number: 17
17 is a prime number.
```

Fibonacci generator:

```text
Enter the number of terms (1-93): 7
Fibonacci Sequence:
0 1 1 2 3 5 8
```
